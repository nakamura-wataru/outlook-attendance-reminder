# 打刻リマインダー

出勤・退勤の打刻を忘れないためのMacアプリです。Outlookの予定表、または自分で設定した月〜金の週間予定に合わせて通知します。

出勤は予定の5分前、退勤は予定時刻に通知します。通知画面からKING OF TIMEで打刻できます。

macOS 11以降のAppleシリコン・IntelのMacに対応しています。

## インストール

ターミナルで次を実行します。このリポジトリにアクセスできるGitHubアカウントが必要です。

```sh
git clone git@github.com:ibj-labo/outlook-attendance-reminder.git
cd outlook-attendance-reminder
bash install.command
```

インストールが終わると「打刻リマインダー」が開きます。次回からはFinderの「アプリケーション」やSpotlightで開いてください。

インストールにはインターネット接続が必要です。

初回にmacOSの確認画面が出た場合は、組織のルールに従い、[Appleの手順](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)を確認してください。

## 通知の設定

アプリの「通知の予定を設定」を開き、使いたい方式を選びます。

### 月〜金の時刻を自分で設定する

1. 「週間予定（月〜金）」を選びます。
2. 曜日ごとに出勤・退勤時刻を入力します。通知しない曜日はチェックを外します。
3. 「保存して開始」を押します。

たとえば出勤を9:45、退勤を18:45にすると、9:40と18:45に通知します。日本時間で毎週繰り返します。祝日もチェックした曜日なら通知します。

### Outlookの予定表を使う

1. 「Outlookの予定表」を選びます。
2. 「OutlookのICSリンクを設定」を押し、自分の予定表のICSリンクを入力します。
3. 接続を確認できると通知が始まります。

ICSリンクはOutlook Webの「設定 → 予定表 → 共有の予定表 → 予定表の公開」で取得します。予定名が見える公開範囲を選び、ICSリンクを使ってください。[Microsoftの手順](https://support.microsoft.com/en-us/outlook/share-your-calendar-in-outlook-on-the-web)

ICSリンクを持つ人は予定表を読めるため、他人に送らないでください。会社で予定表の公開が許可されていない場合は、週間予定を使ってください。

「出社」「出勤」「退社」「退勤」の予定が通知対象です。「9:45 出勤」「18:45 退社」のような名前にも対応します。会議や終日予定は通知しません。

通知時刻は予定名に書いた時刻ではなく、予定表に登録した日時で決まります。出勤予定が0:00〜9:45のブロックなら終了時刻の5分前、通常の9:45開始の予定なら開始時刻の5分前に通知します。退勤は予定の開始時刻に通知します。

方式を切り替えるときは、選び直して「保存して開始」を押します。入力済みの週間予定とOutlookのICSリンクは残ります。

## KING OF TIMEで打刻する

初回はアプリの「KING OF TIMEで打刻」を押します。普段使うMyレコーダーのURLを確認し、接続先のサーバーとログイン方式を選んでログインしてください。

通知が来たら「打刻画面を開く」を押し、Myレコーダーの「出勤」「退勤」ボタンで打刻します。最初は小さな通知だけを表示し、再通知のときも打刻画面は閉じた状態から始まります。

まだ仕事中なら、10分後・30分後・1時間後・2時間後から選び、「再通知」を押します。初期選択は10分後です。「閉じる」を押すと、その通知と再通知を終了します。

ログインや打刻ができない場合は「ブラウザで開く」を使ってください。接続先やログイン方式は「接続設定」から変更できます。

「表示をテスト」で通知画面を確認できます。テストでも「打刻画面を開く」を押すと実際のKING OF TIMEが表示されます。出勤・退勤ボタンを押すと勤怠に記録されます。テストでは再通知を予約しません。

## 通知の停止・再開

アプリの「通知を停止」「通知を再開」で切り替えます。停止・再開の状態はMacを再起動しても引き継ぎます。

設定画面を閉じても通知は続きます。Outlookやブラウザを開いておく必要はありません。通知は約1分遅れることがあります。Macのスリープ中は通知を表示できません。

## 更新・削除

更新するには、最初に取得したフォルダで次を実行します。設定はそのまま引き継ぎます。

```sh
git pull
bash install.command
```

削除するときは「通知を停止」を押してから、アプリをゴミ箱へ移動してください。
